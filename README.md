# Javier Torres: Portafolio de Data Analytics

Analista de datos con 14 años de experiencia en inteligencia de mercados, en transición al análisis de datos. Trabajo con SQL, Python y Power BI para convertir datos en decisiones comerciales.

Cada proyecto tiene su propia carpeta con README (contexto, datos, metodología, resultados) y, según el caso, código y documentación técnica.

## Proyectos

| Proyecto | Herramientas | Qué encontrarás |
|---|---|---|
| [Andes Capital Real Estate: estrategia comercial](./andes-capital-real-estate-powerbi) | Power BI, DAX, Power Query | Modelo en estrella, medidas DAX documentadas, concentración de ingreso por canal y cohortes de recompra |
| [Rappiplus: ventas, margen y marketing](./rappiplus-powerbi) | Power BI, DAX, Power Query | Modelo de datos, medidas DAX, margen por producto y peso del gasto de marketing |
| [ConnectaTel: análisis de clientes](./connectatel-analisis-clientes) | Python (pandas, matplotlib, seaborn) | Notebook con análisis de uso por edad y tipo de plan |

> Los tres son proyectos de formación con datos simulados. Los archivos CSV originales no se incluyen en el repositorio.
